# Excel-дашборд отдела продаж

Демонстрационный проект для контроля результатов менеджеров.

## Задача
Собрать в одном отчёте показатели отдела и сотрудников,
сравнить результаты с планом и показать динамику по дням.

## Возможности
- План/факт по отделу и менеджерам.
- Конверсии звонков в диалоги и назначенные встречи.
- Оценочная загрузка сотрудников.
- Выбор периода отчёта.
- Динамика показателей на графиках.

## Инструменты
Excel, СУММЕСЛИМН, динамические массивы,
сводные таблицы и диаграммы.

## Как пользоваться
1. Скачать и открыть Excel-файл.
2. Внести результаты менеджеров на лист «Исходники».
3. Внести количество новых лидов на лист «Лиды компании».
4. Выбрать период на листе «Сводка» в E9:E10.
5. Нажать «Данные → Обновить всё».

## Особенности
Исходные данные вводятся вручную.
Интеграция с CRM не реализована.
Время встреч оценивается по 60 минут.
Работа в CRM и переписка в загрузке не учитываются.

## Данные
В проекте используются демонстрационные данные.
